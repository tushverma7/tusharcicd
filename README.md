# Node.js Hello World App with GitHub Actions CI/CD, SonarQube & DockerHub Integration

This project showcases a complete CI/CD workflow using **GitHub Actions** for a simple **Node.js Hello World application**, integrated with **SonarQube**, and **DockerHub** for container image storage.

---

## Features Completed

- Built a Hello World Node.js application
- Setup and integrated SonarQube for static code analysis
- Connected GitHub Actions to SonarQube
- Built and pushed Docker image to DockerHub
- Pulled and ran the image locally from DockerHub

---

## Technologies Used

- Node.js
- Docker
- GitHub Actions
- SonarQube
- DockerHub
